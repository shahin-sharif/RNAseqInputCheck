# Changelog

## 0.1.0 — 2026-10-02

Initial release: read-only validation of sample sheets, GTF, Salmon, BAM and
restricted design formulas; optional FASTA index and R package checks; offline
HTML, JSON and TSV reports; synthetic examples and automated tests.

This release does not perform full alignment decoding, empirical strandedness
inference or end-to-end downstream analysis validation.
